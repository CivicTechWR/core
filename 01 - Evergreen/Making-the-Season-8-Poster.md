# Process
1. Base image retrieved from https://en.wikipedia.org/wiki/Nokia_3310
   ![[Pasted image 20260830220343.png|89]]
2. Opened in Gimp
3. Color shifted to get pink screen
4. Screen font retrieved from https://webdraft.hu/fonts/nokja-original/
	1. ![[NokjaOriginalSmallBold.ttf]]
5. Process for text
	1. Context: Font was too light, scaled weirdly
	2. Write text out in font in desired size
	3. Select font layer -> get selection from text
	4. Paste over selection in new layer
6. Misc
	1. Clone + heal tool to remove text, etc.

## Cons
